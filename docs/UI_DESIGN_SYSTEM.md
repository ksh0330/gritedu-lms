# 관리자 CMS UI 디자인 기준

2026-10-19 관리자 CMS 통합 배포 기준. 공개 화면의 공통 `.btn` 자체를 변경하지 않는다. 실제 소스는 `assets/css/components/button.css`, `assets/css/pages/admin.css`, 각 관리자 페이지 CSS와 HTML이다.

동일 계층의 버튼은 높이·글자·패딩·줄 높이를 함께 맞춘다. 헤더·행·모바일 터치 버튼은 역할에 따라 다른 크기를 허용한다. 상태 전환과 순서 저장은 다른 작업이므로 버튼 안내와 성공·실패 문구도 구분한다.

다운로드 버튼은 처음 진입·조회 중·조회 실패·필터 결과 0건에서 비활성화하고 title과 목록 빈 상태로 이유를 안내한다. 조회 성공 후 결과가 있으면 활성화하며 파일 생성 중에도 비활성화·`aria-busy`를 적용한다. 파일명에는 현재 필터 범위와 건수를 넣고, 로드된 전체 필터 결과를 내보낸다. CSV/XLSX를 같은 버튼에 동시에 연결하지 않는다.

## 입력·모달·상태

- 관리자 `.form-group`의 text, URL, email, select, textarea는 공통 테두리·8px 모서리·14px 글자·10px 12px 여백을 기준으로 한다. 모바일에서는 글자 16px 이상으로 확대한다. 페이지 전용 예외는 해당 페이지 선택자 안에 둔다.
- 모달은 제목과 닫기 버튼, 오류 영역, 저장 중 잠금, Escape, Tab 순환, 닫은 뒤 실행 버튼으로 포커스 복귀를 확인한다. 중첩 이미지 편집 모달은 별도로 검증한다.
- 로딩, 0건, 조회 실패를 구분한다. 저장 성공은 실제 쓰기 완료 뒤 알리고 실패하면 재시도 가능한 화면 상태를 유지한다.
- 관리자 일반 작업 결과는 `#statusMsg`를 재사용하는 `admin-toast.js` 상태 알림으로 표시한다. 계정·학생·강사·회원·강좌·반·사이트(학원 안내 포함)·팝업·시간표 관리에 적용한다. 상단 중앙(기본 80px, 640px 이하 안전영역 16px), 최대 너비 420px, 모바일 좌우 16px에 성공·오류 배경과 글자색을 적용한다. 연속 알림은 이전 타이머를 취소하고 마지막 표시부터 약 2.7초 후 내용과 배경을 숨긴다. X 닫기 카드형 `toast.js`는 로그인·로그아웃 등 인증 알림에 유지한다. 모달 오류 영역과 위험 작업 확인 모달은 유지하고 관리자 상태 알림은 모달보다 위에 표시한다. 일반 사용자 역할 화면의 토스트 위치는 변경하지 않는다.
- 관리자 전용 CSS는 페이지 영역으로 범위를 제한한다. `main.css`가 모든 페이지 CSS를 가져오므로 범위 없는 `.btn.sm` 규칙은 다른 관리자 화면의 버튼을 바꿀 수 있다.

## 품질 게이트

1440·768·390px의 동일 viewport에서 팝업과 사이트 강사진 도구를 비교하고 computed height, padding, font-size, line-height와 가로 넘침을 기록한다. 기능 QA와 시각 QA는 따로 판정한다. 합성 로컬 브라우저 PASS는 운영 배포나 운영 역할 계정 Verified가 아니다. 실제 운영 저장은 별도 승인 범위에서만 수행한다.


## 2026-11-02 선택 목록 drawer·순서 피드백·검색창·조회 버튼 (로컬 구현, 브라우저/운영 미확인)

**선택 목록 관리 패널 = 모달 drawer.** 열려 있는 동안 페이지 위에 겹치는 `role="dialog" aria-modal="true"` 패널이며 인라인 토글이 아니다(`admin-catalog-drawer.js`). 기존 `<details id="…CatalogPanel">`과 하위 ID/data/이벤트/초안/저장 계약을 유지하고, 초기화 성공 시에만 `.is-drawer`와 헤더 트리거(중립 `.btn.sm`, 36px/14px)를 켠다. 실패하면 기존 details 펼침이 남는다. 폭 `min(640px,100vw)`, ≤640px 전폭, 머리·하단 sticky(패널 위 padding 0), 입력 모바일 16px. 목록이 작으므로 **검색 입력을 넣지 않는다**(이미 불러온 작은 목록을 한눈에 표시). 열기·닫기·이동은 DB 조회 없음, 닫아도 초안 유지(트리거 '저장 전' 배지), 확인창이 위에 있으면 Escape/Tab을 넘긴다. 적용: 강좌 선택 목록, 강사 과목, 반 선택 목록, 시간표 기준값(4곳 모두).

**순서 변경 피드백(`admin-order-feedback.js`, `.is-order-moved`).** 이동 직후 ①이동한 행 약 1.8초 강조(정적 배경+윤곽, `prefers-reduced-motion: no-preference`에서만 약한 pulse) ②보이는 `role=status` 줄 또는 화면 밖 aria-live에 '‘이름’을(를) N개 중 M번째로 옮겼습니다.' ③같은 방향 이동 버튼으로 포커스 복귀(끝에 닿으면 반대 버튼). **초안과 저장을 문구로 구분**한다: 초안은 '아직 저장 전 변경입니다 + 저장 버튼 안내'와 `.admin-draft-badge`, 즉시 저장 목록(팝업)은 저장 성공 뒤에만 '저장했습니다'. 이동 버튼 크기는 바꾸지 않았다. 적용: 시간표(그룹·학교급·이미지), 사이트 강사진 순서(드래그·정렬), 팝업 ↑↓, 강좌/강사/반 선택 목록.

**목록 검색창.** 경계선은 바깥 `.admin-toolbar__search-wrap` 하나(focus-within 링)이고 안쪽 input은 테두리·배경·그림자 없음(다크 모드 `html[data-theme=dark] input` 규칙 재적용 차단 포함). 6개 관리자 목록 페이지 범위에서만 적용하며 공개/학습 화면의 같은 class는 건드리지 않는다. `.admin-toolbar` 직계 wrap은 `flex:1 1 280px; max-width:420px; min-height:40px`, ≤768px 44px(검색 버튼 40px), ≤640px(기본 목록 외 도구줄) 전폭. Enter/검색 버튼 확정 검색과 서버 조회 규칙은 그대로.

**명시 조회 버튼 계약.** 명시적으로 불러오는 목록(대시보드·학생·회원·계정 목록)은 최초 주황 '현황 불러오기' → 조회 중 '불러오는 중...' 비활성+`aria-busy` → 성공 후 회색 '새로고침', 실패하면 '현황 불러오기'로 돌아가 재시도하고 본문은 빈 상태/로딩/실패 문구를 구분한다. 자동 조회 페이지(강사·반·강좌·시간표)는 자동 조회와 '새로고침'을 유지하며 지연 조회로 바꾸지 않는다.

**문구 원칙.** 파괴·기록 보존·권한·실패 안내는 유지하고, 운영자 판단에 도움이 없는 내부 식별값/저장 경로/구현 설명은 화면에서 빼서 문서에 둔다(예: 시간표 이미지 저장 위치 `settings/timetableCatalog.groupCatalogs.<그룹>.scheduleImages`는 ROLE_TEST_PLAN·DATABASE_SCHEMA 참조). 시간표 이미지는 '추가·삭제·순서는 이미지 저장 필요, 이름·URL·구분은 즉시 저장되며 저장 전 변경이 있으면 함께 저장'을 화면에 명시한다.

1440/768/390px computed 수치는 아래 '선택 항목 관리 공통 규격' 참조. 로그인 화면 확인 절차는 ROLE_TEST_PLAN §12.


## 2026-11-02 선택 항목 관리 공통 규격 (격리 브라우저 측정, 로그인·운영 미확인)

규칙은 `assets/css/pages/admin.css` 한 곳에 두고 페이지 CSS에 다시 쓰지 않는다. 표시 구조는 `renderStringCatalogTagsHtml`, 시간표는 `schedule-groups-admin.js`와 `admin-timetable.js`가 같은 클래스를 쓴다.

| 요소 | 1440px | 768·390px |
| --- | --- | --- |
| 입력칸·'추가' 버튼 | 높이 40px, 모서리 8px, 테두리 1px, 글자 14px | 높이 44px, 글자 16px |
| ↑·↓·× | 36×36px | 44×44px |
| 패널 | 오른쪽 고정, 폭 640px | 768px 폭 640px, ≤640px 전폭 |
| 행 | 한 줄: 번호·색상·이름·↑↓·× | 768px 한 줄, ≤480px 이름 첫 줄·조작 다음 줄 |

- **위계:** 관리 버튼은 중립 `.btn.sm .admin-catalog-open-btn`. 패널은 제목→짧은 설명→안내 3줄(저장 시점·초안 유지·제거 영향)→항목 카드→요약·위치 안내→닫기/변경 취소/주황 저장. 머리·저장 영역과 요약은 스크롤해도 보인다.
- **순서:** 항상 한 열이다. 여러 열로 나누면 이동 결과를 읽기 어렵다.
- **색상:** 이름과 분리한 14px 점. 색만으로 상태를 전달하지 않는다. 편집 UI는 없다.
- **제거 표현:** ×는 '목록에서 제거'이고 중립 색이다. 공개 시간표에서 통째로 빠지는 시간표 그룹 삭제만 위험 색을 쓴다. 이미지 카드도 '삭제' 대신 '제거'다.
- **요약(`admin-draft-summary.js`):** 저장본과 초안을 비교해 추가·이름·색상·노출·순서·제거 건수를 보여주고 상세를 펼친다. 되돌리면 빠지며, 저장 성공·변경 취소에 초기화되고 실패에 유지된다. 서버 기록·collection·listener를 만들지 않는다.
- **접근성:** 위치 안내는 `role=status` 한 줄만 읽히도록 목록 컨테이너의 `aria-live`를 제거했다. 노출/숨김은 `aria-pressed`. 이동·제거·이름 변경 뒤 포커스를 유지하고, 저장 중에는 패널을 `inert`로 잠근다.
- **시간표 이미지:** 페이지 주 영역을 유지한다. 추가·제거·순서·수정은 즉시 저장하며 별도 이미지 저장/취소 버튼은 없다. 폼은 960px 이하 2열·560px 이하 1열이다.

측정은 실제 빌드와 합성 데이터의 헤드리스 Chromium 기준이다. 절차와 남은 확인은 ROLE_TEST_PLAN §12.


## 2026-11-02 강좌·팝업 모달 간격 (로컬 확인)

강좌 support/편집 및 팝업 편집은 전역 `.modal-header`의 음수 margin을 부분 상속하지 않도록 scoped selector에서 margin/padding 전체를 지정한다. 헤더 아래 독립 본문/스크롤 영역까지 20px을 확보하고, 제목 위 간격은 강좌 편집13~16px, support19~21px, 팝업21px로 확인했다(1440/768/390px의 실제 HTML/CSS 격리 화면). 기존에 양호한 학생·강사·회원·정리 모달의 전역 스타일은 변경하지 않는다. 측정은 합성 내용 기준이며 로그인 앱의 긴 본문/포커스/스크롤 QA와 운영 Verified는 별도다. 상세 상태는 MAINTENANCE_LOG 2026-11-02 기록에 있다.


## 2026-11-02 시간표 이미지 즉시 저장·필터

시간표 이미지는 저장 버튼 없이 즉시 저장하며 초안·요약·변경 취소를 두지 않는다. 필터는 공개와 같은 전체+노출 학교급이고, 이미지가 있는 숨김 학교급만 '(숨김)'으로 함께 표시한다. 추가는 주 행동(주황), 제거는 위험(빨강). 선택 목록 요약은 '변경 N건'이고 종류별 내용은 상세에 둔다. 관리 버튼은 첫 화면부터 보이고 이전 펼침 토글은 없다. 이미지 선택지에는 저장된 학교급만 사용한다. 기준값 초안과 이미지 즉시 저장을 혼합하지 않는다.


## 2026-11-02 강사 선택 목록·삭제 확인 후속

강사 관리도 버튼 이름을 ‘선택 목록 관리’로 통일한다. 과목 카드 아래에 ‘공개 상세 페이지 표시’ 체크박스를 배치하고 요약·변경 취소·목록 저장을 공유한다. 별도 상단 표시 설정 섹션과 저장 버튼은 제거했다. 표시 설정은 저장 전 초안이며 프로필 미리보기는 저장된 설정을 따른다. 추가 CSS는 해당 강사 패널의 fieldset 범위로만 제한한다.

시간표 그룹 삭제 확인은 하나의 모달에 그룹명·연결 학교급별 이미지 이름과 수량·기준값 저장 시점·보존 대상(R2 원본/학교급/오프라인 반)을 함께 안내하고 취소/삭제 두 행동을 제공한다. 소개영상 미리보기와 공개 렌더링은 동일 파싱·순서·중복 제거 규칙을 쓴다. 운영 Verified는 별도다.
